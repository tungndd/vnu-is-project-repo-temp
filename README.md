# VNU-IS Project Repository (Temporary)
A repository for storing and managing projects by students and faculty at VNU-IS.

## Purpose
- Store code, data, and documentation for academic projects.
- Enable collaboration and reuse.

## Folder Structure
- `src/`: Source code (e.g., Python scripts).
- `data/`: Sample datasets.
- `docs/`: Documentation.
- `tests/`: Unit tests.
